# ETL Pipeline Portfolio

This repository contains a collection of **Extract, Transform, Load (ETL) pipeline projects** demonstrating practical data engineering concepts, tools, and workflows.

Each subdirectory represents a **self-contained project**, focused on a specific ETL pattern, data source, or technology stack.

## Purpose
This portfolio is intended to showcase:
- Practical data engineering skills
- ETL design patterns and tradeoffs
- Python-based data processing workflows
- Experience gained through formal training and hands-on projects

## Audience
- Hiring managers and technical interviewers
- Data engineers and database professionals
- Anyone reviewing my technical portfolio

## Repository Structure
Each project lives in its own directory and includes:
- A project-specific `README.md`
- Source code
- Configuration files
- Notes or documentation relevant to that pipeline

Example structure:

```text
etl-pipeline-portfolio/
├─ python-data-engineering/
│ ├─ README.md
│ ├─ src/
│ ├─ data/
│ └─ notebooks/
├─ future-project-1/
│ └─ README.md
└─ future-project-2/
  └─ README.md
```
